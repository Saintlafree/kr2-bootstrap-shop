# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина гаджетов, разработанную с использованием Bootstrap. Это отдельная реализация той же предметной области, что и в КР №1 (репозиторий `kr1-html-css-shop`), но на CSS-фреймворке.

## Используемый CSS-фреймворк

Bootstrap 5.3.3, подключён через CDN jsDelivr:

- `bootstrap.min.css` в `<head>`;
- собственный `css/custom.css` подключён после Bootstrap, чтобы при необходимости переопределять его стили;
- `bootstrap.bundle.min.js` перед `</body>`, нужен для раскрытия меню на мобильных экранах и для компонентов в следующих работах.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы (`container`, `row`, `col-12 col-md-8` / `col-12 col-md-4`);
- Bootstrap-навигация (`navbar`, `navbar-expand-lg`, кнопка `navbar-toggler`, закреплена через `sticky-top`);
- hero-блок на сетке: фон на всю ширину через `container-fluid`, содержимое в `container`, две колонки `col-12 col-lg-6`;
- блок преимуществ (`row g-4`, `col-12 col-md-4`, `h-100`);
- сетка популярных товаров (`col-12 col-md-6 col-lg-4`) с бейджами `badge`;
- блок цифр (`col-6 col-md-3`): 2 колонки на телефоне и 4 на планшете и компьютере;
- подвал страницы на сетке;
- utility-классы: `my-5`, `mb-*`, `p-4`, `py-*`, `g-*`, `text-center`, `text-md-end`, `bg-light`, `shadow-sm`, `rounded`, `d-flex`, `gap-3`.

### Как работает сетка на разных экранах

| Блок | Телефон (< 768px) | Планшет (≥ 768px) | Компьютер (≥ 992px) |
|---|---|---|---|
| Hero | 1 колонка | 1 колонка | 2 колонки (`col-lg-6`) |
| Преимущества | 1 колонка | 3 колонки (`col-md-4`) | 3 колонки |
| Популярные товары | 1 колонка | 2 колонки (`col-md-6`) | 3 колонки (`col-lg-4`) |
| Цифры | 2 колонки (`col-6`) | 4 колонки (`col-md-3`) | 4 колонки |

Страницы `catalog.html`, `product.html` и `order.html`, на которые ведут ссылки меню, будут добавлены в следующих практических работах.
